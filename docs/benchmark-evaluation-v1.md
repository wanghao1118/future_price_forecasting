初始版本输入日范围为 2026-09-08 至 2026-10-27，答案日范围为 2026-09-09 至 2026-10-28。SC 假日较多，因此 30 个交易日覆盖的自然日较长。这里使用的是供应商日线 `close`，不将其标成交易所官方结算价。

题目示意：

> 已知某日某具体月份合约的日 K 收盘价为 X，请预测下一交易日的日 K 收盘价，回答一个具体价格数值。

题目文件与真实标签分开保存。版本哈希绑定问题、标签、实际行情及来源快照；更新数据生成新版本，已开始的运行固定使用原版本。

## env01 的两个 agent

`time gate agent` 使用离线模式，只从冻结的本地已爬取新闻中选择。拒绝演示、审核排除、无正文、无原始日期、日期冲突以及晚于时间边界的记录。精确时间先转换到对应交易所时区，要求新闻日期不晚于输入日，且严格早于目标日；只有日期的来源保留日粒度，不编造时分秒。

每题最多提供 8 篇最近的合格新闻，每篇最多提供 4000 字符；正文截断会明确标记为节选并保留原始长度与审计。没有合格新闻时，仅根据当日价格预测。每轮冻结同一份新闻快照，后台爬虫后续更新不会改变本轮输入。

历史回填的新闻按已保留的原始发布日期筛选；事后抓取的网页版本未额外联网核验，相关记录带 `historical_version_unverified` 标记。因此本次结果反映这份本地新闻快照和日期筛选规则，不把它宣称为已独立证明全文版本当时可得的历史回放。

`evaluation agent` 从模型原始输出提取唯一有限数值预测价，读取隔离保存的真实标签，逐题计算 `|预测价 − 真实价|`，按品类计算平均绝对误差（MAE）。不能解析、模型失败或发生禁止工具调用的题目单独记录失败，不用当前价或零误差替代。

WTI、Brent、SC 各自报告 MAE 及成功题数；不同币种不混成一个 MAE。只有同测试集、同环境、同品类的完整结果适合比较，未完成结果显示临时 MAE。

## GPT6.1 Sol

- 模型 `gpt-6.1-sol`，Codex CLI，推理强度 `medium`。
- 每题新建独立临时工作目录和临时会话，不把不同日期问题放进同一上下文。
- 关闭联网搜索、shell、执行、插件、应用、浏览器、多 agent 和记忆工具；检测到搜索、执行或 MCP 调用的结果不计分。
- 模型只收到单题公开字段及 time gate 放行的本地新闻，不收到真实标签、其他题目或评分。
- 原始输出、模型输入哈希、工具轨迹、新闻筛选记录、预测价、真实价及绝对误差逐题保存，可恢复未完成运行。

页面的运行历史来自真实评估文件，不填充演示成绩。初始完整运行编号为 `20261029T072418Z-5471e758`。
