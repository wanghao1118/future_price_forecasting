# 记忆泄漏 Benchmark

在 `Benchmark → 记忆泄漏` 审阅 100 道填空题、答案与新闻引用。每月 10 个不同事件，每个事件引用一条新闻、编写一道单空题。年份沿用现有历史新闻库的 2026 年，月份为 1—10 月，以原文已核验的 UTC+0 首发时间为准。题干中的数据所属期、报告发布日、政策生效日可以不同，不以它们替换首发月份。

## 选题与证据

从当前 SQLite 正式事件记录中逐条阅读、编辑遴选，排除演示记录和相关性审核不通过的记录。优先选择对金融与原油市场有明确影响的政策决议、宏观数据、供需报告、重大地缘变化和能源贸易政策；兼顾月内事件差异，不把同一事件的多条转载作为不同题目。重大程度是编辑判断，并非机械排名；现有库偏重原油及相关宏观金融，不能代表所有金融市场。

每道题包括稳定题号、归属月份、事件及重要性说明、单空题干、参考答案和可接受的等价写法、正文中的连续原文证据，以及新闻 ID、标题、来源名、首发时间和原文 URL。预测、估算和媒体报道保留归属，题干不将它们当作事后实绩。数字题在题干中固定币种、单位、时期和统计口径。新闻原有核验状态随引用保留；归档相关性与时间核验不等于独立核实报道的全部事实。

### 时效性标准（v2）

填空考查当次新闻新公布的事实：当期数据、当次决策内容、调整幅度、金额、规模、期限或事件进展。日期用于定位该次报道，单纯在长期常识题前加日期不符合标准。复审逐题检查两个问题：去掉日期后，是否仍能凭人物身份、地理或定义答出；是否可由题干给出的其他数字和固定规则直接算出。符合这两类情况的题要重写或更换新闻。

例如，委内瑞拉总统姓名不能作为此次事件的时效性考点；题干“阿曼首都”会直接泄露会谈地点的解题方式；给出 PMI 位于临界点即可推得 50；给出其他政策利率后利用固定利差推算，也不能充分测试该次报道的记忆。周期数据和政策利率可以保留，但须明确数据所属期或会议，并去掉这些解题捷径。

100 道题均记录 `temporal_focus`（当期数据、政策决定、事件进展或预测更新）和 `temporal_rationale`（该题为何依赖对应新闻）。页面在出题依据中显示中文考点及“时效性依据”。这些是逐题编辑复审的说明，自动字段校验不能替代内容判断。

构建器只读新闻库，核对每月恰好 10 题、合计 100 题、唯一题号/题干/新闻 ID/链接、同月事件名不重复、一个填空、答案及可接受别名未出现在题干、答案属于证据且证据逐字存在于正文，并要求记录时效性考点与理由。它沿用正式新闻的精确首发时间校验，保存正文及原始时间证据指纹。最终 JSON 冻结后，页面无需重新查询新闻库即可查看原有题目，来源链接或事件库记录后续变化也不会更改参考答案。

## 使用边界

页面与完整 JSON 用于人工审阅，包含答案与引用。模型测试须另建独立闭卷会话，只传入 `case_id` 和 `question`；禁用联网、检索、工具、引用内容和外部记忆。不能将完整 JSON、事件标题、证据、答案或别名送入待测模型。建议每题独立会话，统一提示词、生成参数和判分规则，保存模型版本、测试日期和原始回答。

建议报告总正确率与分月正确率；数字需遵守题干单位，并允许无关空格、全半角和等价数字格式的规范化。歧义或超出参考别名的回答应依据判分理由复核，不能默认用字符串包含匹配判对。题库首次构建时未发起模型调用；后续 `Exp00-extend` 使用独立闭卷环境运行所有已配置模型，由 Codex CLI evaluator 判分，详情见 [env00-extend](env00-extend-memory-evaluation.md)。

本测试只能观察历史事实记忆：正确回答可能来自训练、推断或猜测，错误回答也不能证明模型没见过新闻。判定训练污染还需要训练数据、模型知识截止时间、独立对照和统计证据；在已经展示答案的会话中提问不能作为闭卷结果。

## 数据与复核

编辑选择清单位于 `newsdesk/fixtures/memory-leakage-2026-h1.json`、`memory-leakage-2026-h2.json`；冻结题库位于 `newsdesk/fixtures/memory-leakage-2026.json`。`source_snapshot` 记录选中新闻的来源与分月计数；`content_sha256` 对冻结题目、引用、方法和覆盖信息取规范化 JSON 指纹，`dataset_id` 带有指纹前缀。构建时间不参与内容指纹，同样内容可复现同一版本。

时效性逐题复审记录位于 `newsdesk/fixtures/memory-leakage-2026-h1-review.json`、`memory-leakage-2026-h2-review.json`；每条记录说明是否改题及其依据，改题保留旧题干与答案。v1 冻结文件另存于本地 `newsdesk/data/benchmark/memory-leakage/versions/`，不与修订后的 v2 混作同一测试集。

```bash
python3 -m newsdesk.memory_leakage validate
# 明确更新编辑清单后，才使用当前新闻库重新构建冻结题库：
python3 -m newsdesk.memory_leakage build --database newsdesk/data/news.sqlite3
python3 -m unittest newsdesk.tests.test_memory_leakage
```

接口 `GET /api/benchmark?kind=memory-leakage` 返回完整冻结题库；增加 `&download=1` 可下载 JSON。别名 `GET /api/benchmark/memory-leakage` 供本机直接使用，前者兼容现有只读公开转发的白名单。接口只读，不修改行情 Benchmark 指针、预测标签、运行记录或新闻。文件缺失、题库内容被修改或校验不通过时返回 503，不使用随机题目或空题库冒充已构建结果。
